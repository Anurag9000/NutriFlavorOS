# Connector Patch Boundary

This repository is currently being updated through a GitHub connector that supports direct file creation and full-file replacement. It does not expose a reliable inline patch primitive in this execution context. Large shared files are therefore changed only when their complete current content can be preserved, while additive authoritative modules and mechanical import/call contracts are preferred for safety.

This is an execution-environment constraint, not a product architecture requirement. It must not be used to weaken tests, provenance, idempotency, authorization, or lifecycle boundaries.
